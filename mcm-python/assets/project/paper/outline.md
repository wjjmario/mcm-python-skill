# English paper planning template

Adapt this source outline to the actual problem; it is not a formatted submission.

1. Official Summary Sheet: write last using verified results.
2. Introduction and problem restatement; map all requested deliverables.
3. Assumptions and justifications.
4. Notation and units.
5. Data sources and preprocessing.
6. Models and solutions: formulate, solve, validate, answer each task.
7. Sensitivity and uncertainty analysis.
8. Strengths, limitations and recommendations.
9. Problem-specific memo/letter, placed as instructed.
10. Conclusions supported by computed results.
11. Verified references and necessary appendices within the main-report budget.
12. AI use report according to the current policy, after the main report.
