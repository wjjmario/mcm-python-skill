# 建模与验证

拆题形成：题面要求位置 → 输出量/单位 → 数据 → 基线/模型 → 验证证据 → 论文位置。模型服务问题，不能将题目改成算法擅长的问题。

建立数据字典：变量、单位、时间/空间粒度、缺失、异常、来源和获取日期。原始文件保持不变，清洗可复现。统一实体标识、单位和时区。缺数据时先判断哪些结论依赖它，再考虑可解释假设、范围估计或明确标记的合成实验。

| 目标 | 基线 | 候选扩展 | 关键检查 |
|---|---|---|---|
| 连续过程 | 守恒关系、简化差分/ODE | 非线性动力系统、空间离散 | 量纲、初边值、守恒、步长收敛 |
| 资源规划 | 小规模穷举/线性规划 | 整数、网络、鲁棒优化 | 可行性、求解状态、最优性差距 |
| 预测 | 均值、季节性、线性模型 | 树模型、时序模型 | 同划分比较、泄漏、残差 |
| 评价 | 等权与透明归一化 | MCDA、Pareto 分析 | 权重依据、排序反转、尺度影响 |
| 网络传播 | 简单图指标/解析模型 | 动态传播、主体仿真 | 图构建依据、重复实验、机制合理性 |
| 政策情景 | 明确机制的情景对照 | 系统动力学、优化与仿真 | 因果与相关区分、可实施性 |

不默认堆叠 AHP、熵权、TOPSIS 或神经网络；复杂方案未获验证支持时保留简单方案。

预测按时间/实体/空间相关性划分，预处理只在训练集拟合；调参与最终评估分开，无标签不能报监督精度。优化解释失败状态和约束违反量，启发式不能称全局最优，小实例与枚举/解析解比较。机理模型检查参数可识别性、极限情形、已知稳态和数值收敛。随机仿真用记录的种子和独立重复，报告区间及抽样依据。

敏感性明确参数、扰动范围依据、控制条件和输出；局部单参数扰动不能称全局分析。不确定性明确噪声/参数分布依据，区分情景范围、预测区间和置信区间。无分布依据时采用有解释的情景范围。记录假设→方程→算法→结果→图表→结论的证据链。
