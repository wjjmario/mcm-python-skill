# 英文论文

使用 `assets/project/paper/outline.md` 作为可调整提纲，按题目要求安排内容和篇幅，不强制固定章节。优先当届官方 Summary Sheet。摘要最后写，呈现实际方法、量化结论和主要局限，数值从结果文件取得。

按子问题解释模型为何适用、变量与单位、数学表达、参数来源、求解方法、验证结果和答案。方程后解释符号及条件，不以算法名称或无关理论代替推导。数值有合理有效位、单位和情景。

维护结果登记表：结论/表图、源结果文件、产生它的命令和配置、正文位置、核验状态。重算模型后同步摘要、正文、表图。不能用演示数值补论文。

引用支持具体主张，读到原文再引用，不编造 DOI/作者/页码。区分题面数据、外部数据、方法、图像及 AI 工具。原创图说明其数据来源。

根据用户需要输出 Markdown、LaTeX 或 Word；使用环境中适用文档能力，实际编译或渲染后检查公式、分页、表格和图。没有编译条件就交付源文件并说明 PDF 未生成。

最终论文的数学公式必须渲染为正常的分式、上下标和希腊字母，不能把 LaTeX 命令、B_i 之类的代码记法直接放入成品正文。PDF 优先使用嵌入字体的矢量公式；Word 使用原生公式对象。源文件可保留公式代码，但交付前检查实际显示。

最终检查每项题目要求是否回应、公式与实现是否一致、结论是否来自实际运行、局限是否诚实，以及匿名性、页眉、格式、页数、引用、AI记录。空 AI 日志不证明未使用 AI。
